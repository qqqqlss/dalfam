# 0002. 생리 기록은 기기 로컬에만 저장

- 상태: 채택
- 날짜: 2026-11-07

## 배경

생리 기록은 건강 정보로, 개인정보 보호법상 민감정보다. 서버에 저장하면 별도 동의, 암호화, 보관·파기 정책, 유출 대응 책임이 생긴다.

## 결정

- 처음에는 기기 로컬(Room, DataStore)에만 저장하고 외부로 전송하지 않는다.
- 로그, 크래시 리포트, 애널리틱스에 건강 데이터를 넣지 않는다.
- 서버 동기화는 별도 ADR로 다시 결정한다. 그때는 AWS 서울 리전을 쓴다.

## 고려한 대안

- 처음부터 서버 동기화 — 기기 변경 시 데이터를 보존할 수 있지만, 법적·보안 부담이 초기 개발 규모에 비해 크다.

## 결과

- 법적·보안 부담이 최소화된다.
- 앱을 지우거나 기기를 바꾸면 기록이 사라질 수 있다. 백업 방식(Android 자동 백업 허용 여부, 내보내기 기능)은 아직 정하지 않았다 — `docs/engineering-checklist.md` 참고.
